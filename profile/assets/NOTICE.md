# Artwork sources

The profile covers compose the outlined muted wordmarks and woodcut bird from [niltavi/niltavi-logo](https://github.com/niltavi/niltavi-logo). The source artwork is preserved; the covers add a background and sun and position the existing assets.

The wordmarks use DM Sans Medium. Its SIL Open Font License is included in [FONT-LICENSE.txt](FONT-LICENSE.txt).
