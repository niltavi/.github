# Repository guidance

Before proposing or making changes, load the [Niltavi project Skill](.agents/skills/niltavi-project/SKILL.md). Follow its steps in order: read the current [Niltavi Rules](https://github.com/niltavi/niltavi-rules#readme), consult [Niltavi Skills](https://github.com/niltavi/niltavi-skills#readme), and read the [Niltavi UI documentation](https://github.com/niltavi/niltavi-ui#readme). Apply the shared rules to your work.

The [organization profile](profile/README.md) and the [repository README](README.md) share the same introduction. Update both when changing that text. Reuse the approved brand assets and keep their [source and license information](profile/assets/NOTICE.md) with the profile covers.

Before publishing, check both rendered documents. Follow the For Agents link and verify that the light and dark wordmarks load and link to niltavi.com.
